# 自动上传和升级脚本

## 功能说明

这个脚本实现了以下功能：
1. 自动检查 `dist/main.zip` 文件是否存在
2. 上传zip文件到指定服务器
3. 调用升级接口执行自动升级脚本
4. 自动执行git提交版本更新（如果有未提交的更改）

## 使用方法

### 1. 仅上传和升级
```bash
npm run upload
```

### 2. 完整部署流程（构建+打包+上传+升级）
```bash
npm run deploy
```

### 3. 查看帮助信息
```bash
npm run upload -- --help
```

## 命令说明

- `npm run upload` - 执行上传和升级流程
- `npm run deploy` - 一键部署：构建 → 打包 → 上传 → 升级

## 执行流程

1. **检查文件** - 检查 `dist/main.zip` 是否存在
2. **上传文件** - 将zip文件上传到服务器
3. **调用升级接口** - 执行自动升级脚本
4. **Git提交** - 自动提交版本更新（如果有更改）

## 注意事项

1. 执行前请确保已先执行构建命令：`npm run build:prod`
2. 确保 `dist/main.zip` 文件存在
3. 服务器地址和认证信息已在脚本中配置
4. 脚本会忽略SSL证书验证
5. Git提交失败不会影响升级流程

## 错误处理

脚本包含以下错误处理：
- 检查zip文件是否存在
- 上传失败自动终止流程
- 升级接口调用失败会提示错误
- Git提交失败会警告但不会中断流程
- 网络超时设置为30秒

## Git提交功能

- 自动检测是否有未提交的更改
- 如果有更改，会执行：
  ```bash
  git add .
  git commit -m "chore(version): 更新项目版本号"
  ```
- 如果没有更改，会跳过提交步骤
- Git提交失败不会影响升级流程

## 日志输出

脚本会输出详细的执行日志，包括：
- 文件检查结果
- 上传进度和结果
- 升级接口调用结果
- Git提交状态
- 错误信息（如果有）

## 依赖项

脚本使用了以下依赖项：
- axios: HTTP请求库
- form-data: 表单数据处理
- fs: 文件系统操作
- path: 路径处理
- child_process: 执行系统命令

这些依赖项已在 `package.json` 中配置并自动安装。
